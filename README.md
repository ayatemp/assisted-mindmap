# Assisted Mindmap

![Assisted Mindmap banner](assets/image.png)

**Assisted Mindmap** は、研究案・事業案・PoC 仮説のような大きなテーマを、AI と相談しながらマインドマップとして広げるローカル Web アプリです。

最初にテーマを作り、ノードを選びながら「子を追加」「AI で深掘り」「Codex に相談」を繰り返して、考えをツリーとして育てます。

## できること

- プロジェクト単位でマインドマップを管理
- プロジェクト検索、作成、削除
- ノード・メモノードの追加、編集、削除
- ノードの自由移動、位置リセット、曲線コネクタ表示
- トラックパッドでの上下左右・斜め移動
- pinch / `Ctrl` + wheel / `Cmd` + wheel によるズーム
- 左右パネル幅のドラッグ調整
- タグの編集・追加
- ユーザー作成ノードと AI 作成ノードの色分け
- `AI 深掘り 5 件` による一括メモ生成
- 右パネルの `Codex` タブでツリーについて相談
- Codex 相談スレッドをプロジェクトごとに最大 5 件保存

## 使い方

### 1. 起動

```bash
npm install
npm run web
```

Expo の出力に表示される URL をブラウザで開きます。

### 2. プロジェクトを作る

ホーム画面でテーマを入力して `作成して開く` を押します。

例:

- `pseudoGT の新しい研究案`
- `LLM を使った企業向け事業案`
- `修士研究の追加実験計画`

作成したプロジェクトはホーム画面に並びます。検索バーからタイトル・概要・ノード本文・メモを横断検索できます。

### 3. ノードを広げる

マップ上のノードを選ぶと、右側の `編集` タブから次の操作ができます。

| 操作 | 内容 |
| --- | --- |
| 子を追加 | 選択ノードの子ノードを追加 |
| 同階層 | 選択ノードと同じ階層にノードを追加 |
| AIで1件 | 現在のツリー文脈から軽い候補を 1 件追加 |
| AI深掘り5件 | 選択ノードから具体的な調査・検証メモを 4〜5 件生成 |
| メモ追加 | 線の上に長文を書けるメモ型ノードを追加 |
| 位置リセット | ノード配置を自動レイアウトに戻す |
| 削除 | 選択ノードと子孫ノードを削除 |

ノードの枠をドラッグすると、EdrawMind のように好きな位置へ移動できます。

### 4. Codex に相談する

右側の `Codex` タブでは、通常のチャットのようにツリーについて相談できます。

例:

```text
この辺のノードで迷ってる。次に何を広げるべき？
```

Codex は、現在のプロジェクト・選択中ノード・既存ツリーを見て、次に追加するとよさそうな候補を返します。候補カードの `この枝を追加` を押すと、そのままノードやメモとしてマップに追加できます。

会話はプロジェクトごとに複数作れます。最新 5 件だけ保存し、それより古い会話は自動で整理されます。

### 5. AI 深掘りを使う

`AI 深掘り 5 件` は、選択ノードから具体的なメモ型ノードをまとめて生成する機能です。

OpenAI API key を設定している場合は `gpt-5.4` と web search を使って調査メモを生成します。未設定、または API 呼び出しに失敗した場合は、アプリ内のローカル候補で生成します。

API key は右側の `設定` タブから入力できます。

## データ保存

このアプリはローカル前提です。Django や外部 DB は使っていません。

保存先はブラウザの `localStorage` です。

- プロジェクト
- ノード
- メモ
- タグ設定
- Codex 会話
- OpenAI API key

別ブラウザや別 PC には自動同期されません。ブラウザのサイトデータを削除すると保存内容も消えます。
